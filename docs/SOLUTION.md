# Solution walkthrough (spoilers)

1. `examine the desk` reveals a note pointing at the books and a magnifying glass. `take the magnifying glass`.
2. `examine the bookshelf`, then `examine the four books`: four digits **4, 1, 7, 2**.
3. `enter 4172 on the drawer` opens the drawer. `take the silver key`.
4. `examine the painting` reveals a wall safe behind it.
5. `use the key on the safe`, then `take the parchment`.
6. `use the magnifying glass on the parchment` reveals the exit code **9358**.
7. `enter 9358 on the door` and you escape.

The solutions are stored in `escape_room/config.py` (`SECRETS`).
